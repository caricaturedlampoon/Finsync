# FinSync — Native Android & Full-Stack Build Guide

This document provides definitive instructions for building, syncing, and running **FinSync** on Android Studio, explaining common Gradle pitfalls, pre-build guardrails, and automated setup scripts.

---

## ⚡ Quick Start Sequence (3 Commands)

If you are cloning or opening the repository on a fresh machine, run these steps in order from the repository root:

```bash
# Step 1: Install Node.js dependencies (including native Capacitor Android plugins)
npm install --legacy-peer-deps

# Step 2: Compile the React web application and sync native Android bridges
npm run build:android

# Step 3: Open in Android Studio or trigger a command-line build
# Option A: Open Android Studio and open the /android folder
# Option B: Run the automated helper script:
./build_setup.sh
```

## 🏗️ Build Lifecycle Explained

FinSync uses a **Hybrid Native-Bridge Architecture**:
1. **Web Layer (`src/`)**: Written in React 19 + TypeScript + Tailwind CSS with offline IndexedDB caches.
2. **Capacitor Bridge (`android/capacitor-cordova-android-plugins/` & `node_modules/@capacitor/`)**: Exposes native APIs (Biometrics, KeyStore, Filesystem, Haptics, Local Notifications, Status Bar, and Native HTTP).
3. **Android Native Layer (`android/app/`)**: Contains native Jetpack Compose / Room (SQLCipher) code, custom Security Verifiers, and the `MainActivity` hosting the web bridge.

```
Project Root
├── node_modules/@capacitor/   <-- Native plugin Android sources reside here
├── src/                       <-- TypeScript/React code
├── dist/                      <-- Built web bundle (generated by 'npm run build')
└── android/
    ├── app/src/main/assets/public/ <-- Copied by 'npx cap sync android'
    ├── capacitor.settings.gradle   <-- References ../node_modules/@capacitor/*/android
    └── settings.gradle             <-- Root Gradle settings with pre-build guardrails
```

## 🚨 Root Cause Analysis: The "No matching variant" Error

### Problem
During Gradle sync in Android Studio, you may encounter:
```text
No matching variant of project :capacitor-status-bar was found... - No variants exist.
```

### Why It Happens
Capacitor links its native Android plugins dynamically via `android/capacitor.settings.gradle`:
```groovy
include ':capacitor-status-bar'
project(':capacitor-status-bar').projectDir = new File('../node_modules/@capacitor/status-bar/android')
```
If you open the `android/` directory in Android Studio **before** running `npm install`, the path `../node_modules/@capacitor/status-bar/android` **does not exist on disk**.

Gradle cannot find a `build.gradle` file at that location, so it generates an empty, dummy fallback project stub without any variants (no `release`, no `debug`). When `:app` attempts `implementation project(':capacitor-status-bar')`, Gradle halts with the variant mismatch error.

### How FinSync Guards Against This
FinSync includes an automatic **Pre-Build Guardrail** in `android/settings.gradle`:
```groovy
def capacitorAndroidDir = new File(rootDir, '../node_modules/@capacitor/android')
if (!capacitorAndroidDir.exists()) {
    throw new GradleException(
        "[FinSync Build Guardrail Error]: 'node_modules' is missing or not installed!\n" +
        "Run 'npm install --legacy-peer-deps' and 'npx cap sync android' before syncing Gradle."
    )
}
```
If `node_modules` is absent, Gradle sync immediately stops with this friendly, actionable error message rather than a confusing Gradle internal stack trace.

## 🔧 Detailed Step-by-Step Instructions

### Step 1: Install Dependencies
From the repository root:
```bash
npm install --legacy-peer-deps
```
*Note: `--legacy-peer-deps` prevents peer resolution conflicts between React 19 and third-party UI libraries.*

### Step 2: Compile & Sync Web Assets
```bash
npm run build:android
```
This executes:
1. `vite build` — Outputs compiled JS, CSS, and HTML into `/dist`.
2. `npx cap sync android` — Copies `/dist` into `android/app/src/main/assets/public/` and updates plugin bindings.

### Step 3: Open in Android Studio
1. Start Android Studio.
2. Select **Open** and choose the **`android/`** folder (NOT the root folder).
3. Wait for the initial Gradle Sync to finish.
4. If Android Studio prompts to configure JDK, ensure **Java 21 (JDK 21)** is selected under `Settings` -> `Build, Execution, Deployment` -> `Build Tools` -> `Gradle` -> `Gradle JDK`.

### Step 4: Assemble or Run
- **From Android Studio UI**: Click the green **Run** (`▶`) button or `Build` -> `Build Bundle(s) / APK(s)` -> `Build APK(s)`.
- **From Command Line**:
  ```bash
  cd android
  ./gradlew assembleDebug
  ```
  The generated APK will be placed at:
  `android/app/build/outputs/apk/debug/app-debug.apk`

## 🛡️ Other Key Configurations & Best Practices

1. **Gradle 8.9 & 9 Readiness**:
   - `android/build.gradle` uses `tasks.register('clean', Delete) { delete rootProject.layout.buildDirectory }` (avoids deprecated Gradle 8 eager task creation).
   - In `android/app/build.gradle`, `matchingFallbacks = ['release']` ensures Capacitor plugins (which only publish `release` variants) seamlessly resolve into debug builds.

2. **Edge-to-Edge & Safe-Area Insets (Android 15 / API 35)**:
   - Android 15 enforces edge-to-edge display by default.
   - All full-screen screens, dialogs, and navigation bars use `pt-safe` and `pb-safe` classes (`env(safe-area-inset-top)` / `env(safe-area-inset-bottom)`) to prevent UI elements from overlapping the notification status bar or system navigation pill.

3. **Native HTTP Networking (`CapacitorHttp`)**:
   - Live stock prices (Yahoo Finance) and Mutual Fund NAVs (AMFI) use `CapacitorHttp` via `src/services/networkClient.ts`.
   - On native Android, requests bypass the WebView's CORS restrictions and include valid browser headers (`User-Agent`, `Accept`), avoiding 401/403 forbidden responses.

## 🩺 Troubleshooting Quick Reference

| Symptom | Cause | Solution |
| :--- | :--- | :--- |
| `No matching variant of project :capacitor-status-bar...` | Missing `node_modules/` | Run `npm install --legacy-peer-deps && npx cap sync android` |
| White screen on app launch in emulator | `dist` or `src/main/assets/public` empty | Run `npm run build:android` |
| `Unsupported class file major version 65` | Incompatible Java version | Use JDK 17 or JDK 21 in Android Studio settings |
| `TargetSdk 35 warning` | AGP compatibility | We are on AGP 8.7.3 and compileSdk/targetSdk 35 |
| Biometric prompt crashes on emulator | Biometrics not configured in AVD | Set up a PIN/Fingerprint in the Android Emulator settings |
